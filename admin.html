Bulk add players

One player per line: First,Last,Position,Nationality,Era,Age,BirthDate,Appearances
Position must be GK, DF, MF or FW. Everything after that is optional, leave blank if unsure. BirthDate as YYYY-MM-DD (e.g. 1996-04-02): if you know it, it's better than Age since the age then updates itself forever.
Example: Jimmy,Bullard,MF,England,Premier League Era,,,

Bulk fix existing players

Same format, but this updates players already in the pool instead of adding new ones, matched by first + last name. Leave any column blank to leave that field unchanged. Use this to fix missing ages/birth dates, correct eras, or refresh appearance counts in bulk.
Example: Ahmed,Elmohamady,,,2012-2017,,,217 only changes the era and appearances, leaves everything else as-is.

Bulk add fixtures

One fixture per line: Opponent,Date,KickoffTime,HomeAway,Competition,Status
Date as YYYY-MM-DD. HomeAway is Home or Away. Competition and Status are optional, Status defaults to Scheduled. Already-added fixtures (same opponent + date) are skipped automatically, so it's safe to paste the same list twice.

Add a matchday

Built as a two-step job: publish the lineup as soon as the team's out, before kickoff, no ratings or score needed yet, then come back after the game, click Edit on it below, and fill in ratings, the final score, and who scored. Saving credits an appearance to everyone in the lineup the first time; editing afterwards only adjusts for players actually added or removed, so filling in ratings later never double-counts anyone.
